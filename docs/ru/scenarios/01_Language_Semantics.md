# Семантика Языка

## Обзор

Язык сценариев Stage-Env — это декларативный DSL для тестирования блокчейн-приложений.

## Основные Принципы

### 1. Декларативность
Описываем **что** тестировать, не **как**:
```yaml
- wait_for_datum: "{{tx_hash}}"  # Декларативно
```

### 2. Fail-Fast
Сценарии останавливаются на первой ошибке:
```yaml
- cli: "wallet info -w missing"
  expect: success  # Падает здесь
```

### 3. Шаблоны Везде
Все строки поддерживают Jinja2:
```yaml
- cli: "tx_create -from {{wallet}}"
```

## Области Видимости Переменных

### Глобальные
```yaml
variables:
  network_name: stagenet
```

### Уровня Шага
```yaml
- cli: "wallet new"
  save_wallet: addr  # Доступно как {{addr}}
```

### Уровня Сьюта
```yaml
# suite_setup.yml
suite_setup:
  variables:
    shared_var: value
```

## Лучшие Практики

1. Используйте осмысленные имена
2. Группируйте связанные шаги
3. Используйте `print` для отладки
4. Явные таймауты
5. Проверки fail-fast
